# Savor by Sree website

The public website for Savor by Sree, an artisan sweet atelier in Dublin.

- `index.html`: the page (design, sections and page script).
- `live.js`: reads the menu, prices, bundles, offers, markets, menu sections and notices from the
  order app's database, and sends website orders into the order app. Change those in the **order app**, not here.
- `data.js`: the built-in copy used only if the database can't be reached.
- `img/`, `hero.mp4`, `poster.jpg`, `logo.jpg`, `pat*.png`, favicons: images and video.

Hosted with GitHub Pages (Settings → Pages → main / root).
